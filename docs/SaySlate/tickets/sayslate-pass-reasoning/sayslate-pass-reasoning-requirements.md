# SaySlate Per-Pass Reasoning — Requirements

Origin: [Original ticket](./sayslate-pass-reasoning-original-ticket.md)

## Requirements

| ID | Condition that must be true | Source |
| --- | --- | --- |
| REQ-001 | The prompt panel (the "writing behavior" icon) has a reasoning on/off switch for the first-pass prompt and another for the second-pass prompt, beside the second pass's existing enable switch. The two switches are independent, so one pass can use reasoning while the other does not. | [Original ticket](./sayslate-pass-reasoning-original-ticket.md), message 2: "I just want to have a toggle for the first pass prompt to turn reasoning on and off, and then for the second pass prompt, you either turn it on and enabled, and then you can also turn on reasoning if you'd like"; "Say you want the first pass to not use reasoning … and the second pass is intentionally for enhancing the coherence"; "the writing behavior, that icon" |
| REQ-002 | The reasoning setting changes only requests sent through a Custom (LM Studio) connection. Requests to other providers are unchanged. | [Original ticket](./sayslate-pass-reasoning-original-ticket.md), message 2: "This is only going to apply to the LM Studio because it's something that we have the ability to throw to the payload, so that removes the ambiguity there with other models." |
| REQ-003 | Every request a pass sends through LM Studio carries that pass's reasoning setting, whichever surface or action starts the pass. | [Original ticket](./sayslate-pass-reasoning-original-ticket.md), message 2: "Then, just throw it on all of them. Anything that goes through." |
